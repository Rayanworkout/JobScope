
- Get credentials generated by Airflow

```bash
docker compose --env-file .env \
  -f airflow/docker-compose.yaml \
  exec airflow-apiserver \
  cat /opt/airflow/simple_auth_manager_passwords.json.generated
```

- Collect dag parsing / syntax / import errors

```bash
docker compose --env-file .env \
  -f airflow/docker-compose.yaml \
  exec airflow-dag-processor \
  airflow dags list-import-errors
```

- Rerun container

```bash
docker compose --env-file .env -f airflow/docker-compose.yaml up  --build -d
```

- Get airflow compose logs

```bash
docker compose --env-file .env -f airflow/docker-compose.yaml ps
```
